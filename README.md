# 蝦皮購物技能

使用**各平台內建的瀏覽器工具**，協助登入、搜尋、查看商品、加入購物車與準備結帳。腳本優先，遇到登入驗證、風控或最後下單時，讓使用者接手**同一分頁**。

入口：[SKILL.md](SKILL.md)。本專案不安裝瀏覽器自動化套件、不另外啟動瀏覽器、不直接接 CDP；使用宿主既有的瀏覽器與接管能力。

## 雛形範圍

- 共用技能文件與可交給宿主瀏覽器執行的 JavaScript。
- 宿主允許腳本讀寫時使用腳本；只允許唯讀時，輸入與點擊交給宿主正式工具。
- 登入檢查、搜尋導航與結果讀取、商品查看、規格與數量選擇、加入及成功提示確認、購物車與結帳交接。
- 搜尋間隔、次數上限、操作鎖、原分頁綁定、加入防重送與人工恢復。
- 沒有最後送出訂單或付款功能。

**0.1.0 是雛形。** 本機測試驗證狀態流程及腳本邏輯，不代表跨平台或蝦皮完整購物驗證通過。商品、購物車及結帳 selector 須觀察實際頁面後設定。首次登入及風控由使用者處理。

## 開始使用

需要 Node.js 22 以上，以及宿主提供的瀏覽器操作、同一工作階段接手與腳本執行能力。沒有第三方執行依賴。

```sh
cp config.example.json config.local.json
node scripts/shop.mjs --help
```

由代理讀取 `SKILL.md`，先取得宿主原分頁識別及能力，再綁定：

```sh
# 識別值須來自宿主實際工具；唯讀腳本介面使用 readonly。
node scripts/shop.mjs bind --session '宿主原分頁識別' --script-mode readonly --takeover-ready
node scripts/shop.mjs plan login
```

`plan` 只輸出待執行操作，由代理交給**原平台的瀏覽器工具**執行，再回報結果；單獨執行 CLI 不會控制瀏覽器。完整範例見 [操作流程](references/usage.md)。

## 平台與驗證

[平台條件](references/platforms.md) 說明 ChatGPT、Claude、Grok 與 Hermes 的整合邊界。此技能不綁定模型，但各產品仍須實際提供所需工具，不能宣稱所有一般聊天介面皆可直接使用。

```sh
npm run check
npm test
```

本機測試不開瀏覽器、不接觸真實帳號、不建立訂單。2026-10-15 已用既有 Codex 瀏覽器確認蝦皮首頁可讀取、唯讀腳本可用，當時尚未登入；其餘購物步驟仍待實站驗收。

蝦皮[官方說明](https://help.shopee.tw/portal/4/article/79734)列有機器人操作或登入的帳號凍結風險；內建瀏覽器與降速也不能保證不被阻擋。遇到阻擋就停止並交接。設計及實站驗收見 [設計與限制](references/design.md)。
