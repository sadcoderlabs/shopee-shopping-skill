# 蝦皮購物技能

使用**各平台內建的瀏覽器工具**，在使用者已登入的蝦皮臺灣站協助搜尋商品、列出連結、解析描述與規格，以及加入購物車。**本版不包含登入、結帳、下單或付款。**

腳本優先；宿主僅允許唯讀腳本時，讀取使用本專案腳本，輸入、點擊與導航使用宿主正式瀏覽器工具。入口：[SKILL.md](SKILL.md)。

## 本版適用範圍

| 功能 | 本版範圍 |
| --- | --- |
| 搜尋商品 | 輸入關鍵字、送出搜尋，讀取當時已載入的商品卡 |
| 列出商品連結 | 提供商品文字、頁面顯示的價格與商品網址，去除重複及追蹤參數 |
| 給定商品網址解析 | 開啟指定商品，核對賣場與商品識別後讀取資訊 |
| 描述與重要規格 | 商品描述原文、品牌、容量、機況、保固、出貨地、認證等頁面提供的欄位 |
| 規格及價格 | 讀取顏色／容量分組、選取與停用狀態；選定規格後重新確認價格與數量 |
| 庫存與購買限制 | 區分有貨、售罄、未知；標明庫存所屬規格，保留數量上限與按鈕狀態 |
| 加入購物車 | 依購物需求核對指定商品、規格及數量後直接加入，無須額外授權或確認；觀察成功提示並防止重送，已有實站成功案例 |

解析結果會列出 `missingFields` 與 `truncatedFields`。沒有顯示的資料回報缺失或未知，不推測機況，也不把單一規格的庫存套用到其他規格。搜尋卡最低價可能來自配件選項，須以選定商品規格的價格為準。詳細欄位見 [商品解析](references/product-parsing.md)。

## 不包含的功能

- **登入流程**：使用者須先在原瀏覽器完成登入、密碼、QR Code、簡訊及 CAPTCHA；技能只檢查是否已登入。
- **購物車管理**：本版不保證穩定開啟或讀取購物車，也不提供購物車全選、刪除、優惠券或配送設定的完整操作。
- **結帳、下單與付款**：不提供可驗收的完整結帳流程，最後購買由使用者自行完成。
- **風控繞過**：遇到驗證或阻擋就交接使用者；沒有自動解 CAPTCHA、偽裝指紋、更換 IP 或重播私有 API。
- **完整商品資料擷取**：不保證取得所有搜尋結果、所有規格組合的價格／庫存、隱藏資料或頁面未提供的資訊。

**0.1.0 仍是雛形。** 以上是目前實作與實測範圍，不代表所有商品頁、所有平台或每次操作皆會成功。頁面改版或欄位缺漏時，須觀察實際頁面、校準 CSS selector，再以技能腳本驗證。

## 適用環境與平台

目前商品網址限 **`https://shopee.tw` 蝦皮臺灣站**，支援 `-i.賣場識別.商品識別` 與 `/product/賣場識別/商品識別` 的完整商品網址。其他站點與短網址尚未列入支援範圍。

宿主須提供：

- 既有瀏覽器分頁的觀察與操作能力，以及可沿用的登入狀態。
- 使用者接手同一瀏覽器工作階段後，代理可恢復原分頁。
- Node.js 22 以上、本機腳本執行與狀態保存能力。
- 明確的頁面腳本權限；唯讀時不得用腳本修改頁面。

技能文件設計供 ChatGPT、Claude、Grok、Hermes 等宿主整合；**是否可用取決於實際執行環境具備上述工具，並非僅有模型或聊天介面即可使用。** 目前實站驗證環境為 Codex 的內建瀏覽器及已連接的 Chrome，其他平台尚未逐一驗證。詳細條件見 [平台條件](references/platforms.md)。

本專案沒有第三方執行依賴，不安裝 Playwright 或 Browser Use 套件、不另外啟動瀏覽器、不自行建立 CDP 連線，也不複製 cookies 到另一個工作階段。

## 開始使用

先由使用者在宿主原瀏覽器完成登入，再準備本機設定：

```sh
cp config.example.json config.local.json
node scripts/shop.mjs --help
```

由代理讀取 `SKILL.md`，先取得宿主原分頁識別及能力，再綁定：

```sh
# 識別值須來自宿主實際工具；唯讀腳本介面使用 readonly。
node scripts/shop.mjs bind --session '宿主原分頁識別' --script-mode readonly --takeover-ready
node scripts/shop.mjs plan login
```

此處的 `plan login` 是已登入狀態檢查，不會替使用者登入。`plan` 只輸出待執行操作，由代理交給**原平台的瀏覽器工具**執行，再以 `record` 回報實際結果；單獨執行 CLI 不會控制瀏覽器。`config.example.json` 中留空的欄位須依實際頁面校準。完整命令見 [操作流程](references/usage.md)，其中保留的購物車與結帳交接雛形不在本版支援範圍內。

## 驗證紀錄

```sh
npm run check
npm test
```

本機 27 項測試及語法檢查已通過；本機測試不開瀏覽器、不接觸真實帳號、不建立訂單。2026-10-15 實站驗證包含：

- 使用者登入後的狀態檢查。
- Steam Controller、iPod 第四代及 iPod mini 搜尋與商品讀取。
- 技能腳本與瀏覽器工具對照商品連結、價格、描述、規格、停用選項及所選規格庫存。
- Steam Controller 加入購物車成功，並曾短暫看到購物車內的商品列；隨後購物車頁面被導向風控錯誤頁，因此不列為穩定支援。

沒有完成結帳、送出訂單或付款的實站驗證。逐項比較見 [基礎操作實測](references/basic-actions.md)，完整解析樣本見 [商品解析](references/product-parsing.md)。

蝦皮[官方說明](https://help.shopee.tw/portal/4/article/79734)列有機器人操作或登入的帳號凍結風險；內建瀏覽器與降速也不能保證不被阻擋。遇到阻擋就停止並交接。設計及實站驗收見 [設計與限制](references/design.md)。
